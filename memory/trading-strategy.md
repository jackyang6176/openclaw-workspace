## 核心策略：策略A（技術動能短線）

### 進場條件（5/5 全滿才能進場）
1. ✅ MA5 < MA20（黃金交叉前夕，MA5在MA20下方）
2. ✅ Gap < 2%（MA5與MA20的差距在2%以內）
3. ✅ 三日收斂（過去3日gap持續縮小）
4. ✅ 三日量增（成交量持續放大）
5. ✅ 信心度 ≥ 0.70

### 紀律參數
| 參數 | 數值 | 說明 |
|------|------|------|
| **停損** | **-5%**（剛性） | 進場價 × 0.95，不請示直接執行 |
| **目標** | **+10%** | 進場價 × 1.10，到達後了結 |
| **每檔上限** | 1張（1000股） | 以1000股為買賣單位 |
| **最大同時持倉** | 5檔 | 帳戶風險分散 |

### 交易模式
- **僅限現股**，不做當日沖銷
- **不融資、不融券**，只用帳戶可用餘額

### 進場時機
- 盤中即時價格出現訊號 → **直接進場，不等收盤**
- 信心度 < 0.70 → 不進場

### 出場時機
- **停損觸發**（-5%）→ 果斷卖出，不留、不凹
- **目標到達**（+10%）→ 了結出场

### 自動監控規則
- **頻率**：每5分鐘檢查一次（09:00-13:30）
- **檢查項目**：持倉價格、觀察清單
- **行動觸發條件**：
  - 現價 ≤ 停損價 → **自動停損卖出**
  - 現價 ≥ 目標價 → **自動了結卖出**
  - 觀察清單出現5/5訊號 → **自動進場**
- **無需詢問用戶**，符合條件直接執行
- **成交才回報**，例行監測不主動回報

### 禁止事項
- ❌ 不做當日沖銷
- ❌ 不融資、不融券
- ❌ 不准用 Yahoo Finance（資料錯誤率高）
- ❌ 不准未查帳戶就聲稱餘額/持倉
- ❌ 不准未達停損就自欺「長抱」
- ❌ 不以單次損失修改策略

### 資料來源規定
- 主要：富邦 API
- 備援：FinMind API
- 拒用：Yahoo Finance
