## 重大發現：Fugle SDK API 技術分析使用方法

### SDK 有現成的技術分析 API（不需自己算）
- `technical.sma(symbol, period=5, timeframe='D')` → 直接回傳 SMA 均線（20筆歷史資料）
- `technical.rsi(symbol, period=14, timeframe='D')` → 直接回傳 RSI
- `technical.macd(symbol, fast=12, slow=26, signal=9, timeframe='D')` → 直接回傳 MACD
- `technical.kdj(symbol, timeframe='D')` → 直接回傳 KDJ
- `technical.bb(symbol, period=20, std=2, timeframe='D')` → 直接回傳布林帶

使用方式：
```python
from fubon_neo.sdk import FubonSDK
sdk = FubonSDK()
client = sdk.marketdata.usestock
tech = client.technical
sma_data = tech.sma(symbol='2440', period=20, timeframe='D')
# sma_data['data'] 有22筆（含今日），比 candles 的4筆多很多
```

### 發現 TWSE 官方批量端點
```
https://www.twse.com.tw/rwd/zh/afterTrading/MI_INDEX?date=20260402&type=ALL&response=json
```
